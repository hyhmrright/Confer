# X100 demo controller manual

This is fictional product data for the Confer demonstration. Do not use it to operate real equipment.

## Power and communication

The X100 demo controller uses 24 V DC power. It exposes a Modbus RTU interface over RS-485. The factory demonstration address is 1, with 9600 baud, 8 data bits, no parity, and 1 stop bit.
